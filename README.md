
# Практическая работа №1
## Цель
Научиться писать программу которая узнает что-то о реальном компьютере,за которым сидит именно она, — прямо во время своей работы.
## 1. Информация о компьютере
Компьютер: DESKTOP-LPUDTR3
Пользователь: User
Дата и время: 17.09.2026 00:32
## 2. Информация об операционной системе
ОС: Microsoft Windows NT 10.0.19045.0
64-битная ОС: True
Совпадает
## 3. Логические процессоры
4 ядра - вывело 4 ядра
Совпадает
## 4. Память процесса
PID процесса: 2928
Память процесса: 19 МБ
Не совпадает
## Контрольные вопросы
1.Из-за того что эти данные хранятся в операционной система и программа делает запрос к ней
2.Предоставляет программе данные, т.е. выступает посредником
3.Означает что ОС может обрабатывать данные с разрядностью 64 бита за такт
4.Показывает число логических процессоров, не обязательно совпадение
5.WorkingSet это объем память который выделен на конкретно этот процесс, а вся ОЗУ это общий объем доступный для всех программ и ОС
6.Из-за того что компьютеры имеют разные характеристики и ОС считывает в коде данные ПК на котором запущенна программа
## Итоговый вывод
В ходе практической работы я научился писать программу которая узнает что-то о реальном компьютере,за которым сидит именно она, — прямо во время своей работы с помощью класс Environment. Программа запрашивает данные у ОС в момент выполнения из-за этого на разных компьютерах будет разный вывод


## Дополнительное задание. Мини-монитор системы
### Что делает программа
Сначала печатает данные о компьютере, а потом выводит свой номер и делает три замера с паузами, сколько оперативной памяти она занимает в данный момент
### Что нового я узнал о классе Process
Я узнал что в C# есть класс Process, с помощью которого программа может "общаться" с процессами ОС
### Сравнение памяти программы и Диспетчера задач
Цифры в программе и диспетчере задач могут немного не совпадать (в моем случае 18 - в программе и 19 в диспетчере), связано это с тем что Windows и .NET считают память по-разному
### Почему значение памяти может немного изменяться
Память процесса не стоит на месте и меняется нагружается новыми процессами или наоборот заканчивает их из-за этого ее потребление может увеличиваться или уменьшаться
